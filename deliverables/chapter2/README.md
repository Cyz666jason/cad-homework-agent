## 已核对的尺寸

### 2-2 / 图 2-54

### 2-5 / 图 2-55

### 2-6 / 图 2-56

保留原图标注：R20、Φ20、总高 40、底座高 10、中间俯视矩形高 30。按图示投影关系，矩形左右边对应主视半圆端点，并与底座两端 R20 的圆心对齐，因此取底座直线段长 40、总长 80、总宽 40。**80 是采用上述对齐关系推得的值，不是截图上单独标出的数值。** 上方宽 20 轮廓与 R20 圆弧的交点由圆方程计算，不按像素估计。
